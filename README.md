# Proxy Manager / Прокси Менеджер

Расширение Chrome Manifest V3 для HTTP-прокси с профилями, PAC-маршрутизацией
и автоматической авторизацией. Сборка: WXT + Vite, интерфейс: React 19.

## Установка и запуск

Требуются Node.js 24.15+ (ветка 24 LTS) и pnpm 10.33.2.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Если pnpm не установлен, команды можно запускать через `npx pnpm@10.33.2`,
например `npx pnpm@10.33.2 install --frozen-lockfile`.
Используется только `pnpm-lock.yaml`.

`pnpm dev` запускает WXT с перезагрузкой расширения. Папка разработки:
`build/chrome-mv3-dev`.

```sh
pnpm build
pnpm package
```

Готовое расширение: `build/chrome-mv3-prod`.
ZIP для загрузки в магазин: `build/proxy-manager-0.6.0-chrome.zip`.

Для локальной установки откройте `chrome://extensions`, включите режим
разработчика и выберите «Загрузить распакованное расширение».

## Языки

Интерфейс поддерживает русский и английский языки через `i18next` и
`react-i18next`. При первом запуске используется язык Chrome: русский для `ru`,
английский для остальных языков. Переключатель «Язык / Language» доступен
на всех экранах; выбор сохраняется локально и действует при следующем открытии.
Имена профилей и введённые данные при переключении не меняются.

Переводы интерфейса находятся в `src/locales/en.json` и `src/locales/ru.json`.
Название и описание на странице расширений Chrome переводятся по языку
браузера через `public/_locales/`; переключатель меняет язык внутри расширения.

## Обновление с Plasmo

Путь production-сборки сохранён: `build/chrome-mv3-prod`. Для уже загруженного
из этой папки расширения выполните `pnpm build` и нажмите «Обновить» на его
карточке в `chrome://extensions`. Удалять установленное расширение не нужно.

Профили хранятся в `chrome.storage.local`; имена ключей и формат данных сохранены.
При переносе репозитория или загрузке расширения из другой папки проверьте ID
расширения: новая установка с другим ID получает отдельное хранилище.
Для такого переноса используйте экспорт/импорт профилей.

## Проверки

```sh
pnpm check
pnpm test
pnpm build
pnpm test:build
pnpm audit
```

DOM-тесты проверяют профили, черновики, импорт, переключение прокси и кнопку Ping.
`test:build` проверяет готовый manifest и запускает собранный фоновый скрипт
с имитацией Chrome API: восстановление настроек, PAC, авторизацию и отключение.
Сетевое подключение к реальному прокси следует проверять в Chrome.

## Структура

- `entrypoints/popup/` — HTML и запуск React.
- `entrypoints/background.ts` — обработчики фонового service worker.
- `src/Popup.tsx` — интерфейс профилей.
- `src/` — настройки, хранение, PAC и авторизация.
- `wxt.config.ts` — manifest, разрешения и параметры сборки.
- `public/icon/` — иконки расширения.
